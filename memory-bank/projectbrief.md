# Project Brief — Kedarnath Portal

Public website for **Kedarnath Annadana Seva Samithi, Siddipet** — the Telugu
free-food (annadanam) camp on the Kedarnath yatra route, run alongside Shri
Kedarnath Langar Committee, Jalandhar.

## Core requirements
- Inform pilgrims and donors: what the seva is, who runs it, how to donate.
- Host member directory, photo gallery, camp updates, visitor reviews, donations.
- Admin members manage camp content (posts today; Gallery & News from 2026-09).
- Free/zero-cost infrastructure wherever possible (temples/NGOs, no budget).

## Source of truth for scope
- `PLAN.md` (repo root) — approved plan for Gallery + News + admin + auth.
- `SETUP.md` — Firebase/Firestore setup and deployment caveats.
